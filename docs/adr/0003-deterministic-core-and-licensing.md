# ADR 0003: Deterministic core and licensing

- Status: Accepted
- Date: 2026-08-04

The basic MVP uses fixed local rules for recommendations and rewards. AI is excluded because structured inputs and deterministic outputs are sufficient; a future natural-language feature may propose drafts but may not silently change recommendation order.

Original code is MIT. Runtime dependencies must use compatible permissive licenses. GPL, AGPL, SSPL, non-commercial, and unknown-license code or assets are excluded from the distributed application.
